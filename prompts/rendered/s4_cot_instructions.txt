Step 1 — Entity extraction: list every object the description mentions.
Step 2 — Order decision: decide an order to place them in — foundational / ground objects first, then anything positioned relative to an already-placed object, working outward through the relations.
Step 3 — Spatial reasoning: going in that order, work out each object's translation (and size, if you had to assume one) using the heuristics below.

Placement heuristics (apply per relation type; +x=east, +y=north, +z=up; "half_h"/"half_w" mean half the object's height/width along that axis):
  on top of X:  z = X.z + X.half_h + self.half_h ; x = X.x ; y = X.y (if several objects share the same support, spread them so they don't overlap — offset along x or y by at least each object's own width).
  east/west/north/south of X:  offset along that axis by at least X.half_size + self.half_size (+ a small margin); keep the other horizontal axis equal to X's, and z equal to X's z unless something else places self vertically.
  northeast/northwest/southeast/southwest of X: combine the two relevant single-axis offsets above.
  above/below X:  z = X.z (+ or -) (X.half_h + self.half_h + margin); x/y equal to X's unless otherwise constrained.
  near X:  place just outside X's footprint (roughly X.half_size + self.half_size + a small gap), any convenient direction.
  a stated distance from X:  place at that distance from X, any convenient direction, combined with a cardinal if one is also stated.
  between X and Y:  place at the midpoint of X and Y (or another point on the segment between them if a third relation constrains it further).
  centered inside X:  place at X's own (x, y), resting at the correct z for whatever self is doing (on the floor, on X, etc.).

Sizes: use the size actually stated in the description when there is one (e.g. "one meter tall" -> height 1.0). When no size is stated:

  - Named furniture/object PROTOs (Table, Chair, Sofa, ...): assume realistic real-world scale for that kind of object (e.g. a chair seat around 0.45m off the ground, a table around 0.75m tall).
  - Whatever size you assume in your reasoning MUST be the exact size you write in the code below — if your placement math assumed a 0.2m box but the code declares a different size, the two will contradict each other and the object will float or clip through the ground.
